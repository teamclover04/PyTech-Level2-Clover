# Project 1 – Student Marks Analyzer

## 📌 Description
This project analyzes student performance data using **Pandas and Matplotlib**.

It calculates average marks, identifies highest and lowest scorers, and generates visualizations.

---

## 🚀 Features
- Load dataset dynamically (no hardcoding)
- Calculate average marks per student
- Identify highest and lowest scorer
- Generate:
  - Bar chart (Average marks per subject)
  - Histogram (Distribution of student averages)

---

## 📊 Dataset Source
Students Performance Dataset (Kaggle):
https://www.kaggle.com/datasets/spscientist/students-performance-in-exams
